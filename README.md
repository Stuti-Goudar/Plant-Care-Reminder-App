# 🌱 Plant-Care-Reminder-App

A mobile-friendly application that helps users keep their plants healthy by tracking watering schedules, fertilizer intervals, and care reminders.

## 🔗 Live Demo & Android App
- **Live Web App:** [https://stuti-goudar.github.io/Plant-Care-Reminder-App/](https://stuti-goudar.github.io/Plant-Care-Reminder-App/)
- **Android APK:** [Download PlantCareReminder.apk](./PlantCareReminder.apk)

## ✨ Main Features
1. **Home Screen** – Clean navigation to add plants, view saved plants, and read care guides.
2. **Add Plant & Reminders** – Save plant names along with custom watering and fertilizer intervals.
3. **My Plants List** – View all tracked plants, upcoming care schedules, and delete plants anytime.
4. **Plant Care Tips** – Quick guides for sunlight, watering, and fertilizer requirements.
5. **Smart Notifications** – Alerts users when plant care is due.
